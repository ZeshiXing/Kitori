# 首次公开发布检查

公开前检查源码与安装器；在已有开发环境上的验证不能代替干净 Windows 机器的检查。

- 项目自身许可证已选为 `GPL-3.0-only`，全文在 `LICENSE`，元数据已同步。确认发布中的作者署名与第三方通知准确；项目许可证不能替代第三方独立许可证。详见[许可与分发](licensing.md)。
- 复核 `THIRD_PARTY.md` 中实际复用/方法参考、Luna 版本接口；不把外部软件、字典、模型打入源码包。
- 检查 Git 候选文件，排除真实配置、环境文件、密钥、令牌、运行库、模型、日志、音频与观看内容；不要打开旧凭证来做扫描。
- 全部自动化测试通过；面板实测三语、未应用/撤销、关闭、下载取消与重启；入口改名后真实启动。
- 在干净 Windows 机器/虚拟机按安装说明验证；检查联网安装器的依赖下载、取消/重试、可选 Luna、快捷方式与首次设置。说明本地模型所需下载量和系统字幕的语言包要求。
- 检查源码 `sdist` 含脚本、插件、配置示例和前端资源，排除本机数据；wheel 只提供 Python 核心，不是完整桌面安装包。
- 实测数字保留设备/版本/时长/统计含义，不宣称未做过的 CER 或普遍延迟指标。
- 主页三语文档和截图一起进入源码包；核对 [素材署名和许可例外](../images/sources.md)。Luna 图含第三方词典界面，不把其 UI、插画或商标整体声明为本项目的 CC/GPL 内容。
- `docs/experiments/`、本机 `AGENTS.md`、日志及私人记录只留本机；即使被误加入 Git，安装器和源码包也要再次排除。检查发布候选文件不包含这些记录及其链接。
- 构建安装器：`python scripts/build_installer.py`。安装器连同匹配源码提供；外部程序在安装时从固定来源下载，不将开发机器的运行库直接打包。
