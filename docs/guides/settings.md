# 设置面板操作

从浮窗齿轮、`Ctrl+,` 或 `Settings.cmd` 打开。顶部面板语言即时保存，不改变识别语言、不下载模型、不应用识别修改。

## 识别与语言：准备后应用

上方状态显示实际运行的来源/模型，下方表单是下次应用的选择。模型、来源、语言、设备、更新间隔、解码与屏蔽词表修改后出现未应用提示，可“撤销未应用修改”。

1. 选择本地模型或 Windows Live Captions。Windows 来源不加载本地模型，隐藏模型专属选项；识别语言在系统字幕窗口中设置，本面板改为“注音语言”。切回本地保留模型/设备。
2. 点击“应用并重启字幕”。资源缺失时按钮为“准备模型与环境并应用”：先下载校验，成功后才应用重启，期间当前识别继续。
3. 下载取消/失败不应用，保留已下载进度和表单供重试。关闭窗口取消该窗口负责的下载，放弃未应用的识别修改。
4. 重启时禁用重复操作，成功、失败或超时后恢复按钮，错误提示对应日志。没有修改也可用按钮手动重启。

更新间隔不是固定字幕延迟；更多 Whisper 候选或标准解码可能更慢。幻觉词表按字面删除，也会删掉真正说出的相同内容。

## 显示与文字：即时保存

无需点击应用。关闭设置不会撤销已经保存的样式和面板语言。

| 设置 | 独立浮窗 | Luna |
| --- | --- | --- |
| 双色颜色、上一句保留、正文行数、空闲清空 | 本面板 | 本面板 |
| 字体、字号、字重、斜体、注音比例、行高、阴影、描边、背景 | 本面板 | Luna 自己的设置 |
| 居中、工具栏、自动高度 | 本面板 | Luna 自己的设置 |

仅 Luna 输出时独立浮窗专属选项禁用；同时输出时可调整独立浮窗，Luna 样式仍由 Luna 管理。依据是**已经应用的显示端**，不是尚未应用的下拉选择。关闭阴影时，其颜色/强度/偏移禁用并保留原值。

“关闭”、窗口 X 与 Escape 仅关闭设置，放弃未应用识别修改；“退出字幕程序”结束项目进程。模型磁盘缓存保留，进程退出释放内存/显存。重启不自动恢复本地媒体播放。
