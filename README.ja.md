# Kitori：ふりがな付き日本語リアルタイム字幕

[简体中文](README.md) · [English](README.en.md) · [日本語](README.ja.md)

Kitori（キトリ）は「聞き取り」（kikitori）を短くした名前です。

日本語の動画やアニメを見ながら日本語を勉強したい人向けの、Windows 用字幕ツールです。

パソコンで再生している音声を聞き取り、ふりがな付きの日本語字幕を画面に重ねて表示します。聞き取れなかった台詞を文字で確かめたり、知らない漢字の読みを見たりできます。LunaTranslator を使っている場合は、字幕を Luna に送って、そのまま辞書検索や翻訳の機能を使うこともできます。

特定のサイトやプレーヤー専用ではなく、パソコンの出力音声を取り込むので、会議、オンライン授業、ライブ配信などにも使えます。認識言語は設定で選べます。対応する言語はモデルによって異なります。

まだ開発途中の Alpha 版です。Windows 用のオンラインインストーラーがあり、ソースから実行することもできます。

## できること

長い台詞が終わるまで待たずに、会話に合わせて字幕を出すことを目指しています。認識途中の文字を先に表示し、続きの音声を聞きながら修正します。ふりがなも文字に合わせて更新し、なるべく表示が揺れないようにしています。

- 日本語の原文にふりがなを付け、確定した文字と認識途中の文字を色分けします。
- 字幕は初期設定で中央揃え、本文は最大2行。新しい文字が一定時間届かなければ消えます。
- フォント、縁取り、影、背景の不透明度、字幕を残す時間を調整できます。
- 単体の字幕ウィンドウはブラウザー不要です。Luna での表示や、両方の同時表示も選べます。
- 読み込めるローカルメディアでは音声の先読みも使えます。先読みが使えないときは、そのままリアルタイム認識を続けます。

音声収録、音声認識、形態素解析には既存のオープンソースの部品を使っています。このプロジェクトでは主に、字幕をいつ更新するか、どの文字を残すか、変化する文字に読みをどう合わせるかを扱っています。[使っているプロジェクトと参考手法](THIRD_PARTY.md)

## 認識と表示の選択肢

| 項目 | 現在の対応 |
| --- | --- |
| ローカルモデル | Whisper、Kotoba-Whisper v2、Qwen3-ASR、Voxtral Mini 4B Realtime、ReazonSpeech K2 v2 |
| システム字幕 | Windows Live Captions。Windows 側で有効化し、認識言語を準備してください |
| 表示先 | 単体の字幕ウィンドウ、LunaTranslator、両方 |
| 設定画面 | 中国語・日本語・英語。画面の言語と認識言語は別々に設定できます |
| 日本語の補助 | Sudachi によるふりがな。Whisper/Kotoba では幻覚フレーズのブロックリストも選択可能 |
| ローカルメディアの先読み | 現在は Whisper/Kotoba に対応。他のバックエンドはリアルタイム認識を継続 |

音声認識はローカルモデルまたは Windows Live Captions を使い、クラウド STT の API キーは不要です。本プロジェクトは音声の原文字幕を出力します。翻訳には、別途設定した Luna の機能を利用できます。[モデルとデバイスの詳細](docs/guides/local-models.md)（中国語）

## インストールと起動

[Kitori-Setup.exe](https://github.com/ZeshiXing/Kitori/releases/download/v0.3.0/Kitori-Setup.exe) を開き、インストール先と認識方法を選んで「インストール」を押してください。専用の Python 環境、依存ライブラリ、選択した認識用の実行環境を準備します。Python の事前インストールや管理者権限は不要です。

| インストール方法 | 用途 |
| --- | --- |
| Whisper turbo / NVIDIA | 対応する NVIDIA GPU で large-v3-turbo を使用 |
| Whisper small / CPU | 対応 GPU がない場合に small を使用。速度は CPU によります |
| Windows ライブ キャプション | Windows 11 のシステム字幕を使用。必要な言語パックは Windows 側で有効にしてください |

ネット接続が必要なインストーラーです。Whisper は約5.1 GBの Tiger 実行環境と0.5～1.6 GBのモデルをダウンロードするので、20 GBの空き容量を推奨します。Windows の字幕を使う場合はこれらのダウンロードは不要です。Luna も任意で選べます。ダウンロードに失敗した場合は、再実行すると続けられます。

完了したら設定を開き、認識言語と表示先を選んでください。初期設定は日本語と単体の字幕ウィンドウです。モデルは後から変更できます。[詳しいインストール手順](docs/guides/installation.md)（中国語）

| 起動ファイル | 動作 |
| --- | --- |
| `Start-Local.cmd` | 単体の字幕ウィンドウを起動 |
| `Start-Luna.cmd` | インストール済みの Luna で字幕を表示 |
| `Start-Both.cmd` | 両方で表示 |
| `Settings.cmd` | 設定を開く |
| `Stop.cmd` | 字幕アプリを終了 |

既定の出力デバイスの音声を取り込みます。ヘッドホンやスピーカーを切り替えた後は再起動してください。設定画面を閉じても字幕アプリは動作を続けます。[設定の操作説明](docs/guides/settings.md)（中国語）

### ソースからインストールする

ソースをダウンロードして `Install.cmd` を開くと、自動で環境を準備します。NVIDIA のツールが見つかれば Whisper turbo、なければ CPU 用の small を選びます。手動の手順はインストール説明に記載しています。ソース環境は Windows x64、Python 3.11 以降が必要で、依存関係のロックは Python 3.13 を使います。

## 使う前に知っておいてほしいこと

短い台詞、BGM、複数人の同時発話、人名や地名などは聞き間違えることがあります。ふりがなも必ず正しいとは限りません。勉強に使うときは、不自然に感じた箇所をもう一度聞いたり、辞書で確かめたりしてください。速さと精度はモデル、パソコン、音源によって変わります。

Whisper、Kotoba、Qwen、Reazon は現在、直近の音声を繰り返し認識して字幕を更新します。Voxtral はリアルタイム用のインターフェースを使います。そのため、更新間隔が短くても、その時間で字幕が出るとは限りません。また、「確定」した文字にも誤認識は残ります。

デスクトップ音声の収録で聞こえるのは、すでに再生された音声だけです。先読みは現在、Whisper/Kotoba と読み込めるローカルメディアに限られます。DRM で保護されたサイトには対応しておらず、Edge の動画プレーヤーの再生時刻との継続的な同期もまだありません。

Luna の EXE、DLL、ソースは変更しません。ただし、ふりがなの拡張はバージョン依存の描画インターフェースを使っているため、Luna の更新後には動作確認が必要になることがあります。

## プライバシーと開発

通常の利用では、収録した音声をディスクに保存せず、既定のログにも認識した文字を残しません。最近の字幕は件数を制限してメモリに保持します。ローカルサービスは `127.0.0.1` のみで待ち受け、字幕を受け取るインターフェースには起動ごとに作るトークンを使います。モデルや実行環境のダウンロードにはネット接続が必要です。Luna のオンライン辞書や翻訳を有効にした場合は、それぞれの設定に従って通信します。

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

自動テストと、実モデル・デスクトップ音声・描画の検証は分けて行います。[貢献と命名規則](CONTRIBUTING.md) · [実行時の診断](tools/diagnostics/README.md) · [公開前の確認](docs/development/release.md)（詳細文書は現在中国語です）
